# Employee Attrition Prediction using Machine Learning

## 📌 Project Overview

This project predicts whether an employee is likely to leave a company using Machine Learning techniques. The goal is to help HR teams identify employees who may be at risk of leaving so they can take proactive retention measures.

---

## 📂 Dataset

- **Dataset:** IBM HR Analytics Employee Attrition Dataset
- **Source:** https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
- **Rows:** 1470
- **Columns:** 35
- **Target Variable:** Attrition
